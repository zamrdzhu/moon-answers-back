The line the Moon says back to everyone who has ever stared up at it, written for make.fun's "The Moon Finally Answers Back" bounty.

## The line

> You wished on me for years. I was just a rock with good lighting.

## Run it

```sh
python3 main.py
```

The program prints exactly one line and writes the same line (no trailing newline) to `/output/entry.txt`.

## Why this line

It works because it is a comeback in the Moon's own voice: patient, ancient, and done listening. Humanity spent centuries wishing on a glowing disc in the sky, and the Moon's answer is gloriously unimpressed — it never granted anything, because it was never anything more than a rock that happens to catch the light well. The deflation is the joke: every wish, every howl, every late-night promise, answered by a celestial body filing itself under "good lighting". It sounds like the Moon because only something that old could be that tired of us. One line, 65 characters, well inside the 240-character gate.
